APDCL.BILLWISE is a full-stack electricity billing management system developed to streamline billing operations, improve data accessibility, reduce manual processing and provide meaningful insights into electricity billing and revenue.
The application integrates a Spring Boot REST API, React frontend and PostgreSQL database to provide a centralized platform for managing electricity bills, extracting billing information, identifying duplicate records and visualizing billing trends.

🚀 Project Overview

Traditional electricity billing workflows often involve handling large volumes of billing statements and manually maintaining billing records.
APDCL.BILLWISE addresses these challenges through a centralized digital platform that supports bill processing, structured data management, duplicate detection, reporting and visual analytics.
The system is designed with a modular full-stack architecture, separating frontend presentation, backend business logic and database operations.

✨ Key Features

Digital Bill Processing: Upload and process electricity billing statements.
PDF Data Extraction: Extract relevant information from uploaded billing documents.
Duplicate Detection: Identify duplicate consumer records and repeated statement-month entries.
Centralized Bill Management: Store and manage structured billing information.
Interactive Analytics Dashboard: Visualize billing and revenue trends using charts.
Recent Billing Insights: View recent billing records and summaries.
Report Generation: Generate and download billing reports in PDF format.
RESTful API Integration: Enable seamless communication between frontend and backend.
Database Management: Maintain billing records using PostgreSQL.

🏗️ System Architecture

The application follows a three-layer architecture:
1. Presentation Layer – React.js
Provides an interactive user interface.
Handles bill uploads and user interactions.
Displays billing records, charts and reports.
2. Application Layer – Spring Boot
Handles business logic and API requests.
Processes uploaded billing documents.
Performs duplicate validation.
Communicates with the PostgreSQL database.
Manages report generation.
3. Database Layer – PostgreSQL
Stores consumer and billing information.
Maintains structured billing records.
Supports data retrieval and reporting.
